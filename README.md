# Air Quality Prediction (Flask + SHAP)

A Flask web app that predicts **CO (Carbon Monoxide) levels** from air quality sensor readings using a Random Forest model, with **SHAP explainability** so you can see *why* the model made a given prediction.

## Features

- Predicts CO concentration from 8 sensor/environmental inputs
- Random Forest Regressor trained on the [UCI Air Quality dataset](https://archive.ics.uci.edu/dataset/360/air+quality)
- **Local explanation**: a SHAP waterfall plot generated per prediction, showing how each input pushed the prediction up or down
- **Global explanations**: SHAP summary (bar) and beeswarm plots showing overall feature importance across the dataset
- Simple, single-page web UI

## Tech Stack

- **Backend**: Flask
- **ML**: scikit-learn (RandomForestRegressor)
- **Explainability**: SHAP (TreeExplainer)
- **Data processing**: pandas, numpy
- **Visualization**: matplotlib

## Input Features

The model takes 8 features from the sensor dataset:

| Feature | Description |
|---|---|
| `PT08.S1(CO)` | Tin oxide sensor response (targets CO) |
| `PT08.S2(NMHC)` | Titania sensor response (targets NMHC) |
| `PT08.S3(NOx)` | Tungsten oxide sensor response (targets NOx) |
| `PT08.S4(NO2)` | Tungsten oxide sensor response (targets NO2) |
| `PT08.S5(O3)` | Indium oxide sensor response (targets O3) |
| `T` | Temperature (°C) |
| `RH` | Relative Humidity (%) |
| `AH` | Absolute Humidity |

> Note: `train_model.py` also generates `feature_names.pkl` and `explainer.pkl`, which `app.py` needs to run. Run the training script first if these files aren't present.

## Setup & Usage

1. **Clone the repo**
   ```bash
   git clone https://github.com/sanskrithavaidya/AIR-QUALITY-PREDICTION.git
   cd AIR-QUALITY-PREDICTION/ML_flask_app
   ```

2. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

3. **Train the model** (generates `model.pkl`, `feature_names.pkl`, `explainer.pkl`, and SHAP summary plots)
   ```bash
   python train_model.py
   ```

4. **Run the app**
   ```bash
   python app.py
   ```

5. Open `http://127.0.0.1:5000/` in your browser, enter the 8 feature values, and get a CO level prediction along with a SHAP waterfall plot explaining the result.
